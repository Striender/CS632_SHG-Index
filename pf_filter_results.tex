\subsection{Effect of Pf\_Filter on Base-Layer Time}
\label{sec:pf-filter-breakdown}

Figure~\ref{fig:pf-filter-breakdown} compares each published system with the same
system plus Pf\_Filter at efSearch 64. Each bar splits the base-layer time per query
into CPU idle time (waiting on memory), distance computation and search overhead,
measured as in Section~\ref{sec:observation}. The base layer accounts for 93--99.8\%
of the full query time, and Pf\_Filter does not change the distance computation.

Pf\_Filter reduces the idle time on every dataset: by 10--15\% on HNSW and by
16--21\% on SHG. On HNSW the total gain is small (0.5--2.6\%), because the search
overhead stays roughly the same. On Enron it even rises from 215 to 221\,$\mu$s, which
cancels most of the saved idle time. On SHG both the idle time and the overhead drop,
so the base layer becomes 8.3\% (Enron), 15\% (GIST1M) and 12\% (SIFT1M) faster.
In all cases the results are identical to the system without Pf\_Filter.
